# Cinema Booking System

A cinema ticket booking system built with Flutter + Spring Boot + MySQL.

## Project Structure

cinema_system_project
├── cinema_system      # Flutter Frontend
└── cinema_backend     # Spring Boot Backend

## Requirements

- Flutter
- Java JDK 17
- Maven
- MySQL

## Run Backend

cd cinema_backend  
./mvnw spring-boot:run

Server runs on:
https://cinema-backend-x2gl.onrender.com/api/showings

showing ：
https://specical-cinema-system.netlify.app/
